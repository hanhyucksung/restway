# RESTWAY 출시 준비 체크리스트

## P0 — 미충족(출시 차단)
- [ ] 지도/장소 검색/경로 API 계약 및 서버 키 발급
- [ ] 전국 휴게소 데이터 수집과 상행·하행 진입 가능 경로 정확도 검증
- [ ] 우회 경로 재탐색 및 통행료·유류비 차액 검증
- [ ] 실제 GPS 경로 스냅핑 및 경로 이탈 처리
- [ ] 메뉴·영업시간·편의시설 실제 검수 및 데이터 갱신 체계
- [ ] iOS/Android 기기에서 HTTPS GPS/중단/오프라인 테스트
- [ ] 정상 빌드와 CI, 라이선스/취약점 점검
- [ ] 개인정보 처리방침, 위치정보 처리 검토

## P1 — 베타 공개 전
- [ ] 장애/접속 오류 모니터링
- [ ] API rate limit·timeout·캐시·예산 상한 적용
- [ ] 웹 접근성(키보드·스크린리더·색 대비) 심화 QA
- [ ] 유가·통행료·차종 정확도 확인 및 예외 케이스
- [ ] 실제 기기 주행 환경 QA(동승자 또는 정차 시 이용)
- [ ] 운영 DB 저장·관리자 페이지·백업 복구

## 구현 원칙
- 시연용 정보를 실제 정보인 것처럼 표시하지 않는다.
- 검증되지 않은 휴게소에 길안내 버튼을 노출하지 않는다.
- 위치정보는 사용자가 명시적으로 켠 경우에만 사용한다.
- 안내 목적과 실제 내비게이션 기능을 혼동시키지 않는다.
